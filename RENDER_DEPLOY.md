# 🚀 MediMap — Render Deployment Guide

MediMap v0.7 is fully prepared for instant deployment on [Render](https://render.com).

You can deploy MediMap in **two ways**:
1. **Option 1 (Recommended — 100% Free Blueprint)**: Use the included `render.yaml` to deploy both the Backend Web Service and Frontend Static Site together.
2. **Option 2 (Single Unified Web Service)**: Deploy a single Web Service that serves both the Express API and the Vite React frontend on a single URL.

---

## ⚡ Option 1: Render Blueprint (Recommended)

1. Log into your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** → Select **Blueprint**.
3. Connect your GitHub repository (`MediMap-v07`).
4. Render will automatically read [`render.yaml`](./render.yaml) and configure:
   - **`medimap-backend`** (Node.js Web Service)
   - **`medimap-frontend`** (Static Site with SPA route rewrites to `/index.html`)
5. Fill in the required environment variables:
   - `MONGODB_URI`: Your MongoDB Atlas connection string (or leave blank to use in-memory testing mode).
   - `JWT_SECRET`: Auto-generated by Render.
   - `GROQ_API_KEY`: *(Optional)* For AI chat assistance.
   - `GEMINI_API_KEY`: *(Optional)* For AI medicine recommendations.
   - `VITE_API_URL`: Set to your newly created backend URL (e.g. `https://medimap-backend.onrender.com/api`).
6. Click **Apply**. Render will build and deploy both services!

## 🛠 Option 2: Deploying Manually

### A. Deploy Backend Web Service
- **Type**: Web Service
- **Name**: `medimap-backend`
- **Root Directory**: `medimap/backend`
- **Runtime**: `Node`
- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Health Check Path**: `/api/health`
- **Environment Variables**:
  ```env
  NODE_ENV=production
  PORT=5000
  MONGODB_URI=your_mongodb_connection_string
  JWT_SECRET=your_secret_key
  GROQ_API_KEY=your_key (optional)
  GEMINI_API_KEY=your_key (optional)
  ```

### B. Deploy Frontend Static Site
- **Type**: Static Site
- **Name**: `medimap-frontend`
- **Root Directory**: `medimap/frontend`
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `dist`
- **Rewrite Rule** *(Crucial for React Router client navigation)*:
  - Source: `/*`
  - Destination: `/index.html`
- **Environment Variables**:
  ```env
  VITE_API_URL=https://medimap-backend.onrender.com/api
  ```

## 📦 Option 3: Unified Single-Service Deployment
If you prefer running the entire app on a **single Render free web service**:
- **Type**: Web Service
- **Root Directory**: *(leave blank — use repository root)*
- **Build Command**: `npm run build`
- **Start Command**: `npm start`
- **Health Check Path**: `/api/health`
- **Environment Variables**:
  ```env
  NODE_ENV=production
  PORT=5000
  MONGODB_URI=your_mongodb_connection_string
  JWT_SECRET=your_secret_key
  ```
The backend will automatically build the frontend, serve the API endpoints at `/api/*`, and serve the React application at `/`.

After deployment:

- Expected response:
  ```json
  {
    "status": "ok",
    "db": "connected",
    "version": "4.0.0"
  }
  ```
